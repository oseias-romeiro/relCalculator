What are relations and their properties?

A relation is a collection of ordered pairs. Each pair represents a connection between elements of a set.

Relations can have important mathematical properties such as: reflexive, symmetric, antisymmetric and transitive.

Relation Properties

Learn the main properties of relations with examples and their matrix representations.

Reflexive

(a, a) ∈ R → a ∈ A
Example:
A = {1,2,3}
R = {(1,1) (2,2) (3,2) (3,3)}

Symmetric

(a, b) ∈ R → (b, a) ∈ R
Example:
A = {1,2,3}
R = {(1,2) (2,1) (2,3) (3,2)}

Antisymmetric

(a, b) ∈ R ^ (b, a) ∈ R → (a = b)
Example:
A = {1,2,3}
R = {(1,1) (2,2)}

Transitive

(a, b) ^ (b, c) ∈ R → (a, c) ∈ R
Example:
A = {1,2,3}
R = {(1,1) (2,2) (1,2) (2,1)}
